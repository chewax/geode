## Definition of Done

Reshape Geode's UX so the git engine disappears for non-technical users while staying fully available to power users: collapsible sidebar sections → repo-level timeline riding a soft linear-restore primitive → humanized save flow → change-aware auto-snapshots → all remaining git surfaces gated behind an Advanced Mode toggle plus ambient save signal and readable diffs. Core value throughout: **non-destructive editing — nothing is ever lost, git stays invisible.**

## Cross-Phase Integration

Integration checker: **5/5 seams OK**, `npm run typecheck` green.

1. **Timeline (default) vs VersionGraph (advanced)** — OK. Timeline renders unconditionally (TIME-02/SIDE-03); VersionGraph/BranchSwitcher/branch-merge buttons/palette-git-commands all gated by `advanced`.
2. **STAT-01 save-status vs Phase 4 snapshots + Phase 3 manual save** — OK. Status computed from git state; auto and manual paths converge on `clean` without contradiction.
3. **DiffView (advanced) vs Timeline change-summary (default)** — OK. Both derive from compare-to-parent git logic; no contradictory diff.
4. **Phase 3 AI-on-save vs Phase 4 "never AI"** — OK (grep-verified). `suggestVersion` only from CommitDialog; snapshot path never touches AiService.
5. **Non-destructive core value** — OK. `bringBack` takes a non-AI safety snapshot before `restoreTree` (working-dir only, HEAD intact); destructive ops warn on pending changes; before-quit/vault-switch commit dirty state.
