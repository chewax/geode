# Phase 1 — UI Design Contract

> Visual and interaction contract for the Sidebar Sections restructure. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> Scope: SIDE-01 (collapsible section stack), SIDE-02 (Notes toolbar actions move to the section header), SIDE-04 (vault switch becomes an inline disclosure). Timeline (SIDE-03) is Phase 2 and out of scope. This is a **pure visual restructure**: no functional regressions to the file tree or git logic. All values below reuse the existing Geode dark-theme system in `src/renderer/src/index.css`.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (custom CSS + CSS variables, no shadcn/Tailwind) |
| Preset | not applicable |
| Component library | none (hand-rolled React functional components) |
| Icon library | lucide-react (monochrome `currentColor`, never emojis) |
| Font | `system-ui, -apple-system, Segoe UI, Roboto, sans-serif` (from `:root`) |

Rationale for `Tool: none`: Geode is an Electron app with an established custom design system defined entirely in `index.css` via CSS custom properties. shadcn/Tailwind would fork the visual language. This phase reuses existing tokens and classes; no design system is introduced.

---

## Spacing Scale

The existing system is a compact ~2px-step scale, not a strict 8-point scale. This phase **reuses the existing values** for visual parity with the current sidebar. Do NOT introduce a new scale.

| Token | Value | Usage in this phase |
|-------|-------|---------------------|
| micro | 2px | Gap between header action buttons (matches `.sidebar-toolbar` gap, `.sidebar-footer-actions` gap) |
| xs | 4px | Chevron→label gap in section header; vertical list padding |
| sm | 6px | Row/header horizontal padding step; icon→label gaps |
| md | 8px | Section header horizontal padding (`padding: 0 8px`); tree row horizontal padding |
| lg | 10px | Inline disclosure list-item vertical padding (matches `.vault-menu li`) |
| indent | 14px | Tree indentation per depth and twisty-spacer width (`INDENT` in FileTree.tsx) — do not change |

Exceptions: The scale is intentionally NOT multiples of 4. Values 2px, 6px, 10px, and 14px are pre-existing tokens retained verbatim for pixel parity with the current sidebar, file tree, and vault menu. Introducing an 8-point scale here would visibly shift every existing row and break the "pure restructure, no regressions" contract.

## Typography

Three sizes, two weights. All present in the current sidebar; no new type tokens.

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Section header label | 11px | 600 (semibold) | 22px (matches header height) | Uppercase "NOTAS" section title; `text-transform: uppercase`, `letter-spacing: 0.5px`, color `var(--muted)` |
| Body / rows | 13px | 400 (regular) | ~20px (row height via padding) | File-tree rows, vault-header name (600 here), inline disclosure list items |
| Hint / empty | 12px | 400 (regular) | 1.4 | Empty-state copy (`.tree-empty`) |

Weights: regular 400 for body/hints; semibold 600 for the section header label and the active vault name. No third weight.

Note on the section header: 11px uppercase semibold in `var(--muted)` is the VSCode-Explorer look and is deliberate — the header is **not** accent-colored.

## Color

The dominant surface (60%) is the editor/main area; the sidebar is the secondary surface (30%). This phase touches only the sidebar, so its own dominant surface is `--panel`.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#16161a` (`--bg`) | App/editor background; also `.tree-rename` input bg |
| Secondary (30%) | `#1c1c22` (`--panel`) | Sidebar background, vault header, section headers, footer |
| Raised / hover (part of 30%) | `#202027` (`--panel-2`) | Row hover, active row bg, disclosure list bg, button hover |
| Border | `#2a2a32` (`--border`) | Section-header divider, sidebar right border, footer top border |
| Muted text | `#9a9aa6` (`--muted`) | Section header label, chevrons, idle icons, dir rows, hints |
| Text | `#e6e6ea` (`--text`) | Row labels, vault name, hovered icon color |
| Accent (10%) | `#b794f6` (`--accent`) | See reserved list below |
| Destructive | `#ff6b6b` | Delete (`.node-del:hover`) only — pre-existing, unchanged |

Accent reserved for (explicit, this phase only):
- The active/open note row text (`.tree-file.active`).
- Selection/focus outline on tree rows (`box-shadow: inset 0 0 0 1px var(--accent)`).
- The `Check` mark and highlighted name of the **currently active vault** in the inline disclosure list.
- The sidebar resizer on hover/drag (`.sidebar-resizer:hover`) — unchanged.

Accent is explicitly NOT used for: section header labels, section chevrons, header action icons (idle or hover), or the vault-header name. Those stay `var(--muted)` → `var(--text)` on hover. This keeps accent scarce and preserves the calm VSCode look.

## Copywriting Contract

All strings in Spanish. Titles use sentence case except the section label, which is uppercase by design (VSCode style).

| Element | Copy |
|---------|------|
| Section label | `NOTAS` (uppercase, always) |
| New-note action (tooltip) | `Nueva nota` — when a folder is selected: `Nueva nota en "{ruta}"` |
| New-folder action (tooltip) | `Nueva carpeta` — when a folder is selected: `Nueva carpeta en "{ruta}"` |
| Sort action (tooltip) | `Orden A→Z (click: Z→A)` / `Orden Z→A (click: A→Z)` (existing, retained) |
| Collapse/expand-all action (tooltip) | `Colapsar todo` / `Expandir todo` (existing, retained) |
| Section collapse/expand (aria-label on header) | `Colapsar sección Notas` / `Expandir sección Notas` |
| Vault header (trigger) | Shows the active vault `name`; `title` = full `vault.root` path (existing) |
| Vault disclosure action 1 | `Abrir carpeta…` (with `FolderOpen` icon) — retained verbatim |
| Vault disclosure action 2 | `Clonar o crear en GitHub…` (with `Cloud` icon) — retained verbatim |
| Empty state (Notes section body) | Heading: `Bóveda vacía` · Body: `Creá una nota o una carpeta con las acciones de la cabecera de esta sección.` |
| Error state | Not applicable — pure visual restructure introduces no new failure paths. Existing vault-switch / file-op errors keep their current handling (toast via `notify()`); do not add error UI in this phase. |
| Destructive confirmation | No new destructive actions in this phase. The existing per-row delete (`.node-del`, `Eliminar` tooltip) is retained unchanged; do not add or alter its confirmation flow. |

Copy fix required: the current empty state string is `Vault vacío. Creá una nota con ＋ o una carpeta con 📁.` — it uses the `＋`/`📁` glyphs, which violate the "Lucide icons, never emojis" constraint. Replace it with the two-line copy above (heading + body), removing the glyphs. This is an in-scope copy correction, not a new feature.

## Interaction Contract

### Sidebar layout (top → bottom)
1. **Vault header** (`VaultHeader`) — fixed at top, VSCode "Explorer"-title style.
2. **Inline vault disclosure** (conditional) — renders directly under the header, in flow, pushing everything below down. No overlay, no fixed positioning.
3. **Section stack** — one `SidebarSection` this phase: **NOTAS** (its body hosts `FileTree`, `flex: 1` to fill available height).
4. **Footer** — Help + Settings icon buttons (unchanged).

### Section header (SIDE-01, SIDE-02)
- Height ~22px; horizontal padding 8px; background `var(--panel)`; bottom divider `1px solid var(--border)`.
- Leading twisty: `ChevronDown` when expanded, `ChevronRight` when collapsed, `size={14}`, `color: var(--muted)` (reuse `.twisty`). Gap 4px to the label.
- Label: `NOTAS`, 11px / weight 600 / uppercase / `letter-spacing: 0.5px` / `var(--muted)`.
- **Whole header is the collapse toggle** (click anywhere on the header row toggles). Header is keyboard-focusable (`tabIndex={0}`, Enter/Space toggles); `aria-expanded` reflects state.
- Right-aligned action cluster (`margin-left: auto`, gap 2px): `FilePlus`, `FolderPlus`, `ArrowDownUp`, `FoldVertical`/`UnfoldVertical` — reuse the exact icons from the old `.sidebar-toolbar`. Icon `size={14}` (down from 16) to fit the compact 22px header; buttons are transparent, `var(--muted)` idle → `var(--text)` on hover with `var(--panel-2)` bg (reuse `.icon-btn` hover treatment).
- Action buttons `opacity: 0` by default, `opacity: 1` on header hover or when any action has keyboard focus (VSCode reveal-on-hover). Use `:focus-within`/`:focus-visible` so keyboard users can reach them.
- **Action clicks must `stopPropagation`** so triggering an action does not toggle the section collapse.
- When the section is **collapsed**, the action cluster is hidden entirely (not just faded) — the actions belong to the section and are meaningless without its body.

### Section body
- Notes body hosts `FileTree` unchanged, scrollable, `flex: 1; min-height: 0; overflow: auto` (reuse `.sidebar-tree` behavior).
- When collapsed, the body is unmounted/`display:none`; the section shrinks to just its 22px header.

### Vault header + inline disclosure (SIDE-04)
- Header row: leading `ChevronsUpDown` `size={14}` (`var(--muted)`), then vault `name` (13px / weight 600 / `var(--text)`, ellipsis on overflow). `title` = full root path.
- Click toggles the inline disclosure open/closed. Escape closes it (retain existing listener).
- Disclosure list renders **in flow** below the header (no `position: absolute`, no `.vault-overlay`), pushing the section stack down:
  - One `<li>` per known vault: name (ellipsis) + `Check` `size={14}` + `var(--accent)` on the active one.
  - Separator.
  - `Abrir carpeta…` (`FolderOpen size={14}`) → `onManage`.
  - `Clonar o crear en GitHub…` (`Cloud size={14}`) → `onNew`.
  - List item padding matches `.vault-menu li` (≈7px 10px), hover bg `var(--panel-2)`.
- Selecting a vault closes the disclosure and calls `onSwitch` only when the target differs from current.
- Disclosure open/closed state is **transient** (component `useState`), not persisted — matching the old popover.

### Persistence
- Per-section collapse state persists in `localStorage`, following the existing `geode.sidebarWidth` pattern.
- Key convention: `geode.section.{id}.collapsed` with value `"1"` (collapsed) / `"0"` (expanded). This phase writes `geode.section.notas.collapsed`. Phase 2 Timeline will use `geode.section.timeline.collapsed` with zero primitive changes.
- The sidebar resizer, width persistence (`geode.sidebarWidth`), sort order, collapse-all, and keyboard behaviors are unchanged.

### States summary
| State | Visual |
|-------|--------|
| Section expanded, header idle | Chevron down, label muted, actions hidden (opacity 0) |
| Section expanded, header hover | Actions revealed (opacity 1), each idle muted |
| Section header action hover | Icon `var(--text)`, `var(--panel-2)` bg |
| Section collapsed | Chevron right, body unmounted, actions fully hidden |
| Vault disclosure closed | Only header row visible; sections sit directly below |
| Vault disclosure open | List in flow below header; sections pushed down; active vault has accent + Check |
| Notes empty | `FileTree` replaced by empty-state (heading + body copy), no emoji glyphs |
