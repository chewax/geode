## Phase Goal

**As a** persona que toma notas (no técnica), **I want to** ponerle un nombre opcional a este momento y que la IA escriba la descripción de lo que cambió, **so that** guardo una versión sin ver jerga de git ni una lista de archivos.

<objective>
Reframe the single existing save modal (`CommitDialog.tsx`) from a commit form into "ponle un nombre a este momento": a top optional autofocused Nombre field mapped to the message title, an editable Descripción field below mapped to the body, a human "N notas cambiadas" summary instead of a file list, no ledger warning, and a Lucide error icon. The dialog now consumes `window.geode.ai.suggestVersion()` (built in Plan 01) to auto-fill both fields and composes `title + "\n\n" + description` on save.

Purpose: This is the user-visible half of the phase — after this plan the user actually experiences SAVE-01/02/03. It depends on Plan 01's `suggestVersion()` + shared `NamedVersion` type existing (typecheck would fail otherwise), so it runs in Wave 2.

Output: rebuilt `CommitDialog.tsx` with two fields, the new IPC call, human summary, Lucide `AlertTriangle` error line, and empty-safe message composition. No other files change: `App.doCommit` already applies its relative-date fallback on an empty message, and `entryLabel` (Plan 01) covers the empty-name label — so the empty case is valid end to end with no App/CSS edits.
</objective>
