<objective>
Make the editor panes preview-aware. Thread an optional `previewOid` prop `PaneView → EditorPane`; in `EditorPane` branch the note-load source to `git.readNoteAt(previewOid, path)` when previewing (falling to a ghost state when the note didn't exist at that commit), guard `flush()` so nothing writes to disk during preview, and pass `readOnly` down to the CodeMirror editor.

Purpose: SOFT-01 (tabs/editor reflect the past, read-only), SOFT-03 (ghost tab for notes absent at the previewed version), SOFT-05 (no editing the past; belt-and-suspenders no-disk-write guard — Pitfall 1).

Output: `EditorPane.tsx` (branch load source + ghost `useState` + ghost placeholder render + `.tab.ghost` className + flush guard + `readOnly={props.previewOid != null}`), `PaneView.tsx` (forward `previewOid`). The prop is OPTIONAL so App can compile before it passes it (App wiring is plan 05). App still renders as today; `npm run typecheck` green.
</objective>
