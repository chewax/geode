## Phase Goal

**As a** persona que toma notas (no técnica), **I want to** ponerle un nombre opcional a este momento y que la IA escriba la descripción de lo que cambió, **so that** guardo una versión sin ver jerga de git ni una lista de archivos.

<objective>
Build the backend engine for the reframed save flow: extend the AI surface so it returns a discriminated `{ title, description }` instead of a one-line string, scope the AI generation diff to `.md` notes (the confirmed bug fix), and trim the timeline label to the first line so descriptions never leak into labels. This is the non-UI half of the phase — after this plan the round-trip `window.geode.ai.suggestVersion()` works end to end, but no dialog consumes it yet.

Purpose: The dialog reframe (Plan 02) needs `suggestVersion()` and the shared `NamedVersion` type to exist and typecheck. The `pendingDiff` `.md` scope corrects the reported bug where the AI describes non-note file changes. The `entryLabel` first-line trim must land before multi-line messages exist (RESEARCH Pitfall 2), so the Fase-2 timeline keeps showing only the human title.

Output: new shared `NamedVersion` type + `geode:ai-suggest-version` channel + preload mapping + main handler; `OpenRouterProvider.generateNamedVersion`; `pendingDiff` filtered to `.md`; `entryLabel` first-line only. All additive/surgical; `npm run typecheck` and `npm run build` stay green with no user-visible change.
</objective>
