## Copywriting Contract

All strings in Spanish. Title-case only on first word. No git vocabulary (commit, message, ledger, archivo-as-path, file list). "notas", not "archivos".

| Element | Copy |
|---------|------|
| Dialog title (`modal h2`) | `Guardar versión` |
| Sub-copy (naming the moment) | `Ponle un nombre a este momento.` |
| Changed-notes summary (replaces file list) | Output of `changedSummary(names)` → `N notas cambiadas` / `1 nota cambiada`. Rendered as a single muted line, NOT a scrollable path list. |
| Field 1 label | `Nombre` (with trailing muted hint `(opcional)` inline or in placeholder) |
| Field 1 placeholder | `Dale un nombre a este momento (opcional)` |
| Field 2 label | `Descripción` + `link-btn` action `regenerar con IA` (shown only when `aiReady`) |
| Field 2 placeholder — AI generating | `Generando descripción con IA…` |
| Field 2 placeholder — AI ready, editable | `Descripción sugerida por IA (editable)` |
| Field 2 placeholder — AI off | `Describí qué cambió (o configurá la IA en Ajustes)` |
| Primary CTA | `Guardar versión` |
| Primary CTA — saving | `Guardando…` |
| Secondary action | `Cancelar` |
| Empty state (no changes to save) | Dialog does not open on an unchanged tree; if reached, show `No hay cambios para guardar.` and disable the primary CTA. |
| Error state (AI generation failed) | `No se pudo generar la descripción` (rendered in `modal-error`, prefixed with a Lucide `AlertTriangle`/`TriangleAlert` icon, NOT the `⚠` glyph the old code used — icons are Lucide only). Saving remains allowed; user can type manually. |
| Destructive confirmation | **None.** Saving a version is additive and non-destructive (core value: nothing is ever lost). No destructive action, no confirmation, no ledger/permanence warning. |

**Removed copy (do not carry forward):** `Vas to versionar N archivos:` + path list, and `Esto crea una versión permanente en el historial (ledger).`

## Interaction Contract (phase-specific)

The crux of this phase is the two-field, AI-discriminated flow. Prescribed behavior:

| Concern | Contract |
|---------|----------|
| Field order | **Name (title) on top, autofocus** → **Description below.** Name maps to first line of commit message; Description maps to the body. |
| Name field | Single-line (`text-input`), optional, editable, autofocus on open. Empty is allowed. |
| Description field | Multiline (`commit-message` textarea, `rows={5}`), editable. |
| On open, AI ready | Auto-generate title + description in one pass (extend `window.geode.ai.*`, e.g. `suggestVersion() → { title, description }`). While generating: both fields show their generating placeholder and are effectively read-only-empty (mirror current `generating ? ''` pattern); primary CTA disabled. |
| On open, AI off | Both fields empty; no generation; primary CTA enabled immediately. |
| Regenerate | `regenerar con IA` (`link-btn` + `RefreshCw`) shown only when `aiReady`; re-runs generation, overwriting BOTH fields; disabled while generating (text → `generando…`). |
| Save enabled when | Always, except while AI is actively generating and except on an unchanged tree. **Saving with empty name AND empty description is allowed** — the version falls back to relative date via `entryLabel`. |
| Cancel / overlay click / Esc | Closes without saving (existing `modal-overlay onClick={onClose}` + stopPropagation on inner modal). |
| Result | Saved message = `title + "\n\n" + description` (title = first line). Flows into `git.graph()` → `entryLabel` (which must be trimmed to first line only) for the timeline label. |
| Icons | `RefreshCw` (regenerate), `TriangleAlert`/`AlertTriangle` (error). Lucide, `size` 12–16, `currentColor`. No emojis, no `⚠`. |
