## Phase Goal

**As a** persona que toma notas (no técnica), **I want to** que la bóveda se guarde sola en una cadencia configurable y antes de acciones riesgosas, sólo cuando algo cambió y sin gastar en IA, **so that** nunca pierdo trabajo aunque me olvide de guardar.

<objective>
End-to-end human verification of the auto-snapshot phase against SNAP-01..04, mirroring the Phase 1–3 UAT checkpoint style (there is no automated test harness in this repo by design — validation is typecheck + build + manual UAT). No code changes: this plan builds the app and confirms the observable behavior, then records sign-off.

Purpose: The phase goal ("the vault snapshots itself on a configurable cadence and before risky actions, only when something changed, and never invoking AI") is only truly satisfied when a human sees the cadence drive real snapshots, confirms an idle vault produces none, confirms the three safety triggers, and confirms zero AI cost. This is the phase gate.

Output: a signed-off UAT (§A–§D) with any issues logged. If issues are found, they are captured for a gap-closure plan; if clean, Phase 04 is complete.
</objective>

<task type="checkpoint:human-verify" gate="blocking">
  <name>Task 2: UAT — SNAP-01/02/03/04 (§A–§D)</name>
  <what-built>
    Automatic snapshots: a new "Guardado automático" section in Ajustes (cadence Manual / 5 / 10 / 15 / 30, default 10 min ON), a main-process timer that commits `"Instantánea automática — {fecha}"` only when content changed and never via AI, and safety snapshots before switching vault and before quitting (time-travel safety snapshot already shipped in Phase 2 via "Volver aquí"). Change detection reuses the existing racy-safe content-hash engine; an unchanged tree never produces a commit.
  </what-built>
  <how-to-verify>
    Run the app (`env -u ELECTRON_RUN_AS_NODE npm run dev`) and open a vault with at least one note.

    §A — SNAP-01 (cadence config + persistence):
    1. Open Ajustes → "Guardado automático". Confirm the section exists with a Clock (Lucide) icon and a select showing Manual / Cada 5 / 10 / 15 / 30 minutos, and that it defaults to "Cada 10 minutos" on a vault that never configured it.
    2. Pick "Cada 5 minutos". Close and reopen Ajustes → confirm it still reads "Cada 5 minutos" (persisted). Fully quit and relaunch the app → confirm it is still "Cada 5 minutos" (persists across sessions).
    3. Pick "Manual (sólo al guardar)". Reopen Ajustes → confirm it stays Manual (NOT silently reset to 10).

    §B — SNAP-02 (only when changed) + SNAP-04 (never AI, relative-date label):
    4. Set cadence to "Cada 5 minutos". Make a real edit to a note (type something) and DON'T save manually. Wait ~5 min. In the sidebar Timeline, confirm a NEW entry appeared whose message is "Instantánea automática — {fecha}" and whose secondary line is a relative date ("hace un momento" / "hace N minutos").
    5. With AI enabled (key + model in Ajustes → Mensajes por IA), note the OpenRouter usage before, trigger/await another auto-snapshot after an edit, then check usage again → confirm ZERO usage delta from the auto-snapshot (AI is never called; cost only rises on a manual "Guardar versión").
    6. Now leave the vault completely untouched for one full cadence (~5 min, no edits). Confirm NO new Timeline entry appears (no empty commit on an unchanged tree).

    §C — SNAP-03 (safety snapshots):
    7. Vault switch: edit a note (leave it unsaved), then switch to another known vault via the vault header. Switch back to the first vault and open the Timeline → confirm a safety snapshot captured the edit you made before switching (nothing lost).
    8. Quit: edit a note (leave it unsaved), then quit the app. Relaunch, reopen the vault, open the Timeline → confirm a snapshot captured the edit made just before quit. (Known MVP limitation: the last <600 ms of just-typed characters at the exact moment of quit may not be captured — verify the bulk of the edit is present.)
    9. Time travel (already Phase 2): edit a note (leave it unsaved), go back in time and choose "Volver aquí" → confirm the pre-existing "Instantánea de seguridad — {fecha}" safety snapshot was taken so the edit is not lost.

    §D — no-op / clean-tree sanity:
    10. With Manual selected, make no edits and confirm no timer-driven snapshots occur at all. Then confirm manually saving a version still works and (with AI on) still uses AI — i.e. this phase did not disturb the manual save flow.
  </how-to-verify>
  <resume-signal>Type "approved" if §A–§D all pass, or describe the issues found (which check, expected vs actual).</resume-signal>
