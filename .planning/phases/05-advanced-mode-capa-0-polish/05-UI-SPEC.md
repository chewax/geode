# Phase 5 — UI Design Contract

> Visual and interaction contract for Phase 5 (Advanced Mode & Capa-0 Polish). Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Scope note:** This is an existing Electron + React app (Geode) with an established hand-written CSS design system. This phase MODIFIES existing surfaces (toolbar, statusbar, Settings, DiffView) and introduces NO new visual language. All tokens below are read from `src/renderer/src/index.css` — do not invent new ones. shadcn/tailwind are intentionally NOT used; introducing a component library is out of scope and contradicts the phase intent.

**Accent (`--accent`) reserved for:** active/primary CTA button state (`.tb-btn.cta`, `.primary`), active toggle "on" state, focus outlines, active Settings nav item. Never applied to plain body text, status text, or the save-status indicator.

**Save-status indicator color:** stays `--muted` (`.save-status`) for all four states — the save signal is ambient, NOT an accent surface. The Lucide icon inherits `currentColor` (muted). Do not color it green/accent.

**Semantic colors (green/red)** are used ONLY inside the diff (line backgrounds + the agregado/quitado legend). They are not general-purpose accents.

## Component & Surface Inventory

Four surfaces change this phase. Each is a modification of existing code, not a new component.

### 1. Modo Avanzado toggle — new "General" section in Settings

- **Location:** `SettingsModal.tsx`. Add a nav button as the FIRST item in `.settings-nav` (above "Mensajes por IA"), and a matching `section === 'general'` block as the FIRST `.settings-section` in `.settings-content`.
- **Nav button:** `<button className={section === 'general' ? 'active' : ''}>` with a Lucide icon + label `General`. Recommended icon: `SlidersHorizontal` (size 15). Mirrors the existing nav pattern exactly (`<Icon size={15} /> Label`).
- **Section heading:** `<h2><SlidersHorizontal size={18} /> General</h2>` + a `.modal-sub` one-liner describing the mode.
- **Toggle control:** a labeled switch (`.field-label` + control row, mirroring the "Cadencia" field pattern). Since no toggle-switch component exists, implement a semantic `<input type="checkbox">` styled as a switch OR reuse the existing button-as-toggle idiom; either is acceptable per CONTEXT discretion. The control must have an accessible label and reflect on/off with the accent color when on.
- **Behavior:** reads/writes via new IPC `window.geode.advanced.get()` / `.set(enabled)` (persisted in `settings.json`). Applies instantly via React state; App.tsx re-reads the flag when Settings closes (same pattern as `aiConfig`/`githubCfg`). No restart.
- **Default:** Off.

### 2. Mode-gated git surfaces (ADV-03)

Conditionally rendered only when `advanced === true`:

| Surface | File / anchor | Default (off) | Advanced (on) |
|---------|---------------|---------------|---------------|
| "Árbol de versiones" toolbar button (`GitBranch`) + `VersionGraph` modal | App.tsx ~945, ~1068 | hidden | visible |
| "Crear rama" toolbar button (`GitBranchPlus`) | App.tsx ~917 | hidden | visible |
| "Integrar rama" toolbar button (`GitMerge`) | App.tsx ~927 | hidden | visible |
| `BranchSwitcher` in statusbar | App.tsx ~1104 | hidden | visible |

**Kept visible in BOTH modes (but humanized in default):** the GitHub push affordance. In default mode it must not read "commit"/"push"/hashes — the sync state folds into the save indicator ("Todo en la nube") and the GitHub status popover (`.status-pop`) must drop git jargon (rewrite "Sin pushear · N commit(s)" to human wording such as "Cambios sin subir · N"). The cloud sync feature itself stays.

**Leak audit (ADV-01):** In default mode, verify NO occurrence of `commit`, `branch`, `merge`, `push`, `HEAD`, or 7-char hashes in visible text, `title`, or `aria-label` of any rendered element. This includes toolbar tooltips, statusbar popovers, and the save indicator.

### 3. Humanized save-status indicator (STAT-01)

- **Location:** `.save-status` span in statusbar (App.tsx ~1095) driven by `statusLabel()` (App.tsx ~1310).
- **Replace** the current glyph+timestamp output (`● guardando…`, `✓ guardado {hora}`, `✓ sin cambios`) with a Lucide icon + one of the four EXACT strings below. **Remove `savedAt.toLocaleTimeString()` entirely** — no literal time.
- **Layout:** icon (size 14, `currentColor`, muted) + text, gap 4px, matching adjacent `.status-item` rhythm.

### 4. Readable diff (DIFF-01/02) — `DiffView.tsx`

- **Header:** replace `Versión {oid.slice(0,7)} vs. actual` with the human label `Cambios del {fecha} — {nombre de versión}`. The component must receive/query version metadata (date + human name) instead of rendering the raw `oid`. Remove the `.diff-oid` hash span. Keep the `X` close button (`.icon-btn`, size 16).
- **Legend (new):** a single row above the file list stating the color key in words: a green swatch + "agregado" and a red swatch + "quitado". Swatch = small filled dot/square using the existing add/del colors. This is required by DIFF-02 (words alongside color).
- **Hunk headers (`@@`):** hidden. In `patchLines()`, stop emitting `kind: 'hunk'` text; instead emit a marker that renders as a subtle divider (a thin `--border` rule, no text) between hunks. Exact divider shape is implementation discretion.
- **"No newline at end of file":** filter/drop these lines in `patchLines()` — never render them.
- **Per-line accessibility:** each add/del line gets an `aria-label` prefixed with "agregado"/"quitado" so screen readers convey change type without relying on color.
- **File-level status label** (`statusLabel()` — "agregado/borrado/modificado") already human; keep it.

## State Matrix — Save Status Indicator (STAT-01)

The four EXACT strings are a literal requirement. No other strings permitted.

| Condition | Text (exact) | Recommended Lucide icon |
|-----------|-------------|-------------------------|
| `status === 'saving'` | `Guardando…` | `Loader2` with `.spin` class (existing spin animation) |
| `status === 'saved'` AND GitHub connected AND `pushCount === 0` | `Todo en la nube` | `Cloud` (already imported/used) |
| `status === 'saved'` AND (no GitHub OR `pushCount > 0`) | `Guardado en este dispositivo` | `HardDrive` (or `Laptop`) |
| `status === 'clean'` | `Guardado` | `Check` |
| otherwise | (empty — render nothing) | — |

Icon choice is CONTEXT-discretion; the recommendations above are consistent with existing imports and conventions. Same text in default and advanced mode (no hash/time added in advanced).

## Interaction Contract

- **Toggle Modo Avanzado:** instant apply, no reload. Flag persisted server-side (`settings.json`) via IPC; App.tsx re-reads on Settings close. Off → git surfaces unmount; On → they mount.
- **Focus / keyboard:** the toggle is keyboard-operable (native checkbox semantics) with a visible focus outline (`--accent`). Settings nav items remain tab-navigable.
- **No layout shift regression:** hiding toolbar buttons in default mode must not misalign the remaining toolbar (`.tb-actions`) — the CTA (`Save`) and command palette buttons stay anchored.
- **Diff divider:** hunk separation is purely visual (thin `--border` rule); it carries no text and is `aria-hidden`.
