<objective>
Construir el backbone del main process para crear un cuaderno LOCAL en 1 click, sin GitHub y sin picker: un util de sanitización de nombre de carpeta Windows, la primitiva `VaultService.createLocal` (colisión con sufijo + siembra atómica de `Bienvenida.md`), y el canal IPC `geode:vault-create-local` cableado end-to-end con su handler (git init + primer commit racy-safe del seed).

Output: 1 archivo nuevo (`vaultName.ts`) + 4 modificados (vault.ts, ipc.ts, index.ts, preload). Superficie `window.geode.vault.createLocal(name, useCustomLocation?)` disponible para el renderer.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| renderer (sandboxed) → main vía IPC `geode:vault-create-local` | El `name` es input no confiable controlado por el usuario que se convierte en una ruta de filesystem bajo `~/Documents/Geode`. |
| main → filesystem (mkdir/atomicWrite) | Creación de carpeta y escritura de archivo bajo una base controlada. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-01 | Tampering / Elevation | handler `vaultCreateLocal` + `createLocal` | mitigate | `sanitizeVaultName` elimina `/ \ : < > " \| ? *` y control chars ANTES de armar la ruta, neutralizando `../` y rutas absolutas; la carpeta se ancla con `join(app.getPath('documents'), 'Geode', candidate)` (base fija). |
| T-11-02 | Denial of Service | `mkdir` con nombre reservado Windows (CON/PRN/…) o ilegal (`:`) | mitigate | Detección de reservados sobre el stem + reemplazo de ilegales + fallback "Cuaderno"; `mkdir` nunca recibe un nombre que lo haga crashear. |
| T-11-03 | Tampering (pérdida de datos) | resolución de colisión de carpeta | mitigate | Sufijo ` (2)`, ` (3)`… resuelto ANTES de `mkdir`; jamás se escribe sobre una carpeta existente (criterio de aceptación DURO = core value "nada se pierde"). |
| T-11-04 | Injection | contenido de `Bienvenida.md` | accept | El seed es una constante fija; el nombre del usuario NO se interpola en el markdown. Sin superficie de inyección mientras el seed no se personalice. |
| T-11-05 | Info Disclosure / Error | fallo I/O (`EACCES`/`EPERM`) en carpetas atípicas | mitigate | try/catch en el handler → Error en español humano (UI-SPEC), nunca fuga del stack crudo al renderer. |
| T-11-SC | Tampering | instalaciones npm/pip/cargo | accept | Esta fase NO instala paquetes nuevos (RESEARCH Package Legitimacy Audit: no aplica). Sin superficie de slopsquatting. |
</threat_model>
