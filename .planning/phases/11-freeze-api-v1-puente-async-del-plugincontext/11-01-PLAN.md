<objective>
Congelar la API v1 del `PluginContext` como contrato público versionado y agregar el chequeo de compatibilidad del host: el manifiesto declara `apiVersion` (además del `minAppVersion` ya existente) y el main rechaza/avisa (vía `InstalledPlugin.error`, que ya se muestra en Ajustes) los plugins incompatibles antes de que el renderer los evalúe.

Purpose: Es el prerequisito de la Fase B — sin un contrato congelado y un gate de compatibilidad, no se puede evolucionar la API a v2 async (puente) sin romper plugins existentes en silencio.
Output: `apiVersion?` en `PluginManifest`, constante `HOST_API_VERSION`, chequeo de compat en `listPlugins`, y el encabezado de "contrato v1 congelado" en `types.ts`.
</objective>
