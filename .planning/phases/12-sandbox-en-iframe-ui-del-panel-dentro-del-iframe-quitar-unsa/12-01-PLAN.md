<objective>
Mover la ejecución de los plugins EXTERNOS del renderer principal a un iframe sandboxed (`sandbox="allow-scripts"`, sin `allow-same-origin`, origen opaco). El eval del código no confiable deja de ocurrir in-window y pasa al bootstrap del iframe; el host solo habla con el plugin por el `MessagePort` de la Fase 11, ahora transferido al iframe. Cierra ISO-01 salvo la UI del panel (Plan 02).

Purpose: Es el corazón del aislamiento (Fase B). Solo aquí el puente de la Fase 11 se vuelve un boundary de seguridad real: el plugin corre con contexto JS/DOM propio, sin acceso a `window.geode`, Node ni globals del host. Es el plan de mayor riesgo (build config del runtime del iframe).
Output: pluginRuntime.ts (lado-plugin autocontenido), el bundle del runtime del iframe con su bootstrap, iframeHost.ts (crea el iframe + srcdoc + transfiere el port), bridge.ts recableado, loader.ts sin eval in-window, la entrada de build del runtime del iframe.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| host renderer ↔ iframe del plugin | código de terceros no confiable corre en el iframe; solo cruza el MessagePort (mensajes serializables) |
| iframe del plugin ↔ red | tráfico de red del plugin (exfiltración) — bloqueado por `connect-src 'none'` |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-01 | Elevation of Privilege | acceso a window.geode/Node desde el plugin | mitigate | iframe `sandbox="allow-scripts"` sin `allow-same-origin` → origen opaco, sin globals del host; el plugin solo recibe el AsyncPluginContext por el port |
| T-12-02 | Information Disclosure | exfiltración de notas/tokens por red desde el iframe | mitigate | CSP del srcdoc con `connect-src 'none'` (Plan 03 quita unsafe-eval del host; la red se abre recién en Fase 13 con permiso `network`) |
| T-12-03 | Tampering | mensaje del plugin invocando un método no permitido en el puente | mitigate | allowlist explícita en `attachHostBridge` (Fase 11, conservada): un método fuera de la lista responde `error`, nunca ejecuta |
| T-12-04 | Denial of Service | plugin en bucle infinito colgando la app | mitigate | el iframe de origen opaco obtiene su propio proceso de renderizado (site isolation de Chromium) → un bucle no bloquea el hilo del host; timeout de init para plugins que no arrancan |
| T-12-SC | Tampering | instalación de paquetes npm | accept | esta fase no instala paquetes (react/react-dom/@codemirror ya son dependencias); sin superficie de cadena de suministro nueva |
</threat_model>
