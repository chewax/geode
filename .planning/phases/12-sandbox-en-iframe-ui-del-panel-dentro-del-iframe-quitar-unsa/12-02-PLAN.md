<objective>
Hacer que la UI de un plugin externo funcione bajo aislamiento (UI-01): el PANEL del plugin se renderiza DENTRO de su iframe (el host reserva el rectángulo en el dock y le pasa tamaño/tema por mensaje); los STATUS-ITEMS de terceros cruzan como un modelo serializable `{id,text,tooltip?,icon?}` (no un Component) y el host los dibuja y actualiza. Los built-ins siguen por el camino in-host con Component, sin cambios. `editorExtensions` sigue no soportado para externos.

Purpose: Completa ISO-01/UI-01 — sin esto un plugin aislado solo aporta comandos. El límite del sandbox obliga a que la UI viva dentro del iframe (paneles) o cruce como datos (status-items), porque un Component/Extension no serializa por el MessagePort.
Output: tipos serializables + mensajes de panel; registros externos en host.ts; despacho en attachHostBridge; implementación de panels/statusBar en el runtime del iframe; fork de PluginPanels y PluginStatusBar; helper de íconos Lucide por nombre; ejemplo extendido con panel + status-item.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| host renderer ↔ iframe del plugin | la UI del panel y el modelo de status-item cruzan como DATOS serializables; el DOM del panel vive en el iframe, nunca en el árbol del host |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-05 | Elevation of Privilege | panel de un externo montándose en el DOM del host | mitigate | el panel se renderiza DENTRO del iframe (react-dom del bundle del iframe); el host solo reserva el rectángulo y dibuja el header — nunca ejecuta el Component del plugin |
| T-12-06 | Tampering | status-item con contenido no serializable / HTML activo | mitigate | el status-item cruza como `{id,text,tooltip,icon}` (strings); el host lo renderiza como texto + ícono Lucide por nombre (mapeo acotado), sin `dangerouslySetInnerHTML` |
| T-12-07 | Elevation of Privilege | externo intentando aportar una Extension viva de CodeMirror al editor del host | mitigate | `editorExtensions.add` lanza Error en español para externos; solo built-ins first-party aportan extensiones |
| T-12-SC | Tampering | instalación de paquetes npm | accept | esta fase no instala paquetes; sin superficie de cadena de suministro nueva |
</threat_model>
