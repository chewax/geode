En src/main/services/ai.ts agregar y exportar una función `export function mapAiError(e: unknown): Error`
(comentario y mensajes en español, siguiendo el precedente de mapBackupError de v1.2). Clasifica el
fallo a partir del texto del error del provider (los mensajes los generamos nosotros en `chat()`:
`OpenRouter /chat devolvió ${status}: ${body}` y `OpenRouter /models devolvió ${status}`):
  - Modelo inexistente/no disponible: el texto contiene "404" o "No endpoints found" (case-insensitive)
    → Error con mensaje: "La sugerencia de IA no está disponible: el modelo configurado ya no existe en
    OpenRouter. Revisá el modelo en Ajustes → IA." (usar la flecha "→", NO emoji).
  - 401 o "auth"/"unauthorized" (o 403) → "La sugerencia de IA no está disponible: la API key de
    OpenRouter fue rechazada. Revisá la API key en Ajustes → IA."
  - Timeout/abort ("aborted"/"timeout") o fallo de red → "La sugerencia de IA no está disponible: no se
    pudo contactar a OpenRouter. Probá de nuevo en un momento."
  - Cualquier otro → "La sugerencia de IA no está disponible en este momento. Podés escribir el nombre y
    la descripción a mano."
